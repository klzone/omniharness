# 外部数据底座模板（data-template）

本目录是 `~/YvanAI/`（个人外部数据中枢）的**空目录骨架与说明**，用于在新机器上
一次性生成规范的目录结构。它只放模板与说明，**不存放真实个人数据**。

## 目录骨架

| 子目录 | 用途 |
| --- | --- |
| `knowledge/` | 个人知识库（Obsidian、文档、参考资料） |
| `memory/` | 长期记忆（决策、对话提炼、项目摘要） |
| `projects/` | 项目日志与状态 |
| `templates/` | 可复用模板（决策记录、日报、项目状态） |
| `backups/` | 备份归档 |

## 初始化

在目标机器上执行：

```bash
./scripts/init-yvan-data.sh
```

脚本会按本骨架在你指定的外部数据根下创建目录，并写入配置。个人数据始终存放在
仓库之外，DSH 升级、清缓存或卸载都不会影响它。

> 规范定义见 [config/yvan-work.yaml](../config/yvan-work.yaml)。
