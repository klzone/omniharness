# 外部数据底座模板（data-template）

本目录是外部数据中枢的**空目录骨架与说明**，用于在新机器上
一次性生成规范的目录结构。它只放模板与说明，**不存放真实个人数据**。

## 目录骨架

| 子目录 | 用途 |
| --- | --- |
| `knowledge/` | 个人知识库（Obsidian、文档、参考资料） |
| `memory/` | 长期记忆（决策、对话提炼、项目摘要） |
| `projects/` | 项目日志与状态 |
| `templates/` | 可复用模板（决策记录、日报、项目状态） |
| `backups/` | 备份归档 |

## 初始化

按上表在仓库外创建目录（默认 `~/OmniDeskData`，可用 `OMNIDESK_DATA_ROOT` 覆盖）。
本仓库不附带个人数据初始化脚本，也不提交个人配置或个人文档。个人数据始终存放在仓库之外，DSH 升级、清缓存或卸载都不会影响它。
