# 周报起草 (Memory Report)

只在用户明确要周报时使用（「周报」「总结/汇总本周工作」）。材料为空就如实说「本周还没有记录」，不要凭空写。

## 一、取数

材料是当周 `库/工作记录/2026-Wxx.md` 原文。只取去向标为 `本周报引用` 的条目；标 `知识卡` / `inbox` / `归档` 的不进正文。一条记载含多个子项时按事实拆开归位。

## 二、五段模板

`本周概述` / `事项进展` / `问题与风险` / `下步计划` / `待确认事项`

- 本周概述：三到五句，只概括实质进展；
- 事项进展：每条一行，写清做了什么、到哪一步；
- 问题与风险：只写记录里明确提到的；
- 下步计划：只写记录里已有的；
- 待确认事项：缺的时间、数据、责任人集中放这里。

只写记录里有的事实，**不得补造**成效、数据、人员或结论；事实冲突就并列指出。

## 三、先展示，后落盘

先把全文展示在对话里请用户确认；**只有用户明确确认后才落盘**到 `库/周报/2026-Wxx-周报.md`。未确认或对话中断都不落盘。

命名固定为 `库/周报/<ISO 年>-W<两位周次>-周报.md`。同名已存在时**不覆盖**：加 `-2` 后缀并说明。

## 四、边界

案件材料、线索、未公开审查调查信息、涉案人员、举报内容不进周报；遇到即停止并说明。
