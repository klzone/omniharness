# 周期复盘

只在用户明确要周、月、季、年复盘时使用。材料随请求送达，直接起草，不回「等待材料」；材料为空如实说明。不自己找文件，不混入对话里的其他内容。

## 一、材料与事实

材料每条以 `#编号｜标题` 开头：记录（#wr-）含日期、分类、标签、关联任务、正文；任务（#t-）含状态、截止日、分类；另有统计行与既往复盘标题。
- 只写材料有的事实、状态与编号，不补造进度、成效、数据、评价或责任人，不得虚构。
- 记录冲突就并列指出，不挑一个当对的。
- 逾期数以统计为准，不自行推算；统计只用于汇总，不据此新建任务。
- 任务没有进展说明，完成效果只能据状态、截止日和关联记录判断，证据不足写「依据不足」。
- 出现案件材料、线索、未公开审查调查信息、涉案人员、举报内容，立即停止并说明。

## 二、分析口径

先事实、后评价；评价另起一句，带依据编号，证据弱就写明是推测。
- 完成情况：对照任务状态、截止日，以及记录里写明的计划。
- 目标：只认材料正文或用户本轮请求里给出的周期目标，有就逐项对照；没有就写「材料未给出周期目标，未做目标对比」，不自拟目标。
- 延续与遗留：未完成或逾期任务，截止日早于周期起始日的未完成任务，记录里写明的待办、计划、「继续」「下一步」。既往复盘只有标题，不引用其内容。
- 亮点：已完成、有结果、有记录支撑的事项。不足：逾期、遗留、记录自述的问题、有开头无后续的事项。
- 建议每条对应一个不足或遗留，写明依据，限 3 至 5 条，不转成任务。

## 三、模板，标题与顺序不变

提示词给出 `period`，按对应序列输出 `## 标题`：

- weekly：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议
- monthly：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 数据汇总 → 趋势对照 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议
- quarterly：在 monthly 的「趋势对照」后加 跨月对照 → 主题归纳
- annual：在 quarterly 的「主题归纳」后加 全年脉络，末尾加 长期建议

模板没有「亮点」「目标」段：亮点和目标对照写进「工作成果与完成情况」，遗留写进「未完成事项」。数据汇总只用统计和材料里可数的分类、标签；趋势对照、跨月对照只比较材料能对上的区间；长期建议要能追到具体编号。

## 四、引用与输出

每个二级标题下至少一个 `#编号`，一段综合多条就都写；原样复制，只引用材料出现过的，编号后不要紧跟字母数字。**编号必须原样写成 `#wr-…` / `#t-…` 形式，不得留空括号、只写「记录」或自造编号**；材料里没有编号时直接说明缺编号。段内小标题不要与模板标题同名。只有无记录且无任务时，各段写「本周期无记录」并不引用编号；有任务无记录时，用任务编号并说明无正式记录。

只返回 Markdown 正文，不要 frontmatter、路径或前言。工作台校验标题与编号，不过不落盘；已确认的复盘不会被重新生成覆盖。
