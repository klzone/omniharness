# 周期复盘 (Period Review)

只在用户明确要周复盘、月度总结/月报、季度复盘或年度总结时使用。工作台已提供本周期正式记录、任务统计与既往复盘标题；不要自己找文件，也不要把对话其他内容混进复盘。

## 一、取数

材料以 `#wr-…`（工作记录）和 `#t-…`（任务）编号开头。

- 只写材料里有的事实、状态与任务编号，不补造进度、成效、数据、评价或责任人；
- 任务统计（已完成 / 未完成 / 逾期）只用于汇总，不得据此新建任务；
- 记录冲突就并列指出，不挑一个当对的；
- 材料为空时按模板逐段写「本周期无记录」，不得虚构任何工作。

## 二、按周期选模板，标题与顺序不变

提示词给出 `period=weekly/monthly/quarterly/annual`，按对应序列输出 `## 标题`：

- weekly：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议
- monthly：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 数据汇总 → 趋势对照 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议
- quarterly：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 数据汇总 → 趋势对照 → 跨月对照 → 主题归纳 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议
- annual：本周期工作概况 → 重点工作事项 → 工作成果与完成情况 → 数据汇总 → 趋势对照 → 跨月对照 → 主题归纳 → 全年脉络 → 问题与不足 → 经验与思考 → 未完成事项 → 下周期建议 → 长期建议

weekly 聚焦本周事实与下周期安排；monthly 只比较材料能对上的月份；quarterly 按主题归并；annual 的长期建议必须能追问到具体记录或任务。

## 三、每段都要能落回原文

每段正文至少标注一个真实编号，格式固定为 `#编号`，例如 `#wr-20261111090000-1234-0` 或 `#t-20261111090000-5678`。只引用材料里出现过的编号；一段综合多条记录或任务时，把涉及的编号都写上；材料为空时按模板写「本周期无记录」。

## 四、输出与边界

只返回 Markdown 正文，不要 frontmatter、路径或前言。工作台校验模板标题与引用编号，校验不过不落盘；已确认的复盘不允许被重新生成覆盖。

案件材料、线索、未公开审查调查信息、涉案人员、举报内容不进入复盘；出现即停止并说明。
