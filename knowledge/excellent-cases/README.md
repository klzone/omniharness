# 历史优秀范文与案例库 (Excellent Cases)

> 当前状态：**尚无实际范例文件**。本目录目前仅有本 README。

## 目录职能
归档本人历史撰写、修改打磨成熟且获得好评的各类纪检监察脱敏文稿范例。

## 计划品类
- `summaries/`：各年度、阶段性优秀工作总结
- `speeches/`：典型经验交流与研讨发言范文
- `reports/`：专项整治、日常督查汇报范文
- `investigations/`：深度调研报告脱敏样本

## 使用准则

供 `material-writing` 与 `document-review` 进行少样本对比学习（Few-shot Guidance）。

**重要约束**：

1. 在放入真实范例前，本目录为空。Skill 在写作时**必须如实说明“未使用历史范例”**，不得凭空声称已参考历史材料。
2. 没有范例时，Skill 仍应按模板与风格规则正常写作，不得因此伪造样例。
3. 放入范例前须先脱敏，且不得包含禁止进入个人 AI 工作站的数据（案件材料、案件线索、未公开调查信息等）。
