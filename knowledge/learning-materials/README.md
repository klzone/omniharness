# 学习资料 (Learning Materials)

> 数据分级：一级（公开）为主，公开出版物、公开课件、辅导材料。
> **内容默认不进入 Git**（含大体积 PDF/PPT）。

## 目录职能
存放学习辅导材料、公开出版物、公开课件与培训资料，供 `knowledge-search` 检索与写作参考。

## 收录范围
- 公开出版的学习辅导材料（如全会精神学习辅导百问）；
- 公开的政策解读、理论学习提纲；
- 公开培训课件（PPT/PDF）；
- 公开出版物节选。

## 使用准则
1. 只收录**公开发布**的材料，不得收录内部或未公开材料。
2. 大体积 PDF/PPT 直接放本目录，不入 Git。
3. 命名建议保留原文件名，便于溯源。
4. 规则见 `docs/OmniDesk-Knowledge-Ingestion-and-Desensitization-Policy.md`。
