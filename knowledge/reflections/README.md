# 个人心得体会与原创文稿 (Reflections)

> 状态：本人原创文稿归档目录。**免脱敏可直接放入**。
> 数据分级：二级（内部）。**内容默认不进入 Git**（见仓库 `.gitignore`）。

## 目录职能
存放本人撰写的心得体会、发言稿、工作汇报、宣传稿等原创文稿，作为个人知识资产长期积累。

## 为什么要单独建这个目录
`excellent-cases/` 存放的是“脱敏后可供 AI 当范文参考”的成熟文稿；
本目录存放的是“本人原创、原样保留”的工作文档。
二者用途不同：**想长期留档 → 放这里；想给 AI 当写作参考 → 先脱敏，再放 `excellent-cases/`。**

## 子目录
- `thoughts/`：心得体会、学习体会
- `speeches/`：交流研讨发言、会议发言稿
- `reports/`：工作汇报、情况报告、专项报告
- `news/`：新闻稿、宣传素材、公众号文稿

## 使用准则
1. 本目录文稿**无需脱敏**即可放入，但请自行确认不含三级红线数据（案件材料、案件线索、未公开调查信息等）。
2. 本目录**整体不入 Git**，仅保留本 README。若要公开到 GitHub，必须另行脱敏并移入 `excellent-cases/`。
3. 放入后可在下方登记表追加一行，记录来源与日期。
4. 完整规则见 `docs/OmniDesk-Knowledge-Ingestion-and-Desensitization-Policy.md`。
