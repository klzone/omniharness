# OmniDesk Discipline

以对话为中枢、场景工作流为骨架、成果档案为沉淀的个人 AI 工作台。首个场景：纪检综合岗位的周报、材料写作与项目跟进。DSH（DeepSeek Harness）是当前锁定版本的可替换执行引擎，不修改其核心，不把它当作产品边界。

## 解决什么问题

专业文字工作需要明确的状态、可回溯的依据、人工复核和成果归档。通用聊天工具一问一答，留不下这些；OmniDesk 把每项工作组织成有状态、有版本、有复核的任务流，数据全部存在你自己的本地目录，随时可迁移。

## 功能地图（当前版本）

- **对话中枢 + 执行时间线**：首页以对话为主要入口；任务执行过程按时间线展示思考与工具调用条目，可展开回看，不是静默等待。
- **工作记录**：随手记、周视图；AI 从记录中提取任务候选，经你确认后落库，任务与记录双向来源可追溯。
- **任务四象限与智能排期**：重要性/紧急性双依据、四象限视图、用户覆盖调整；按工作时间与容量生成排期建议，锁定与已确认安排不被覆盖，冲突显式提示。
- **知识库**：原始资料（Raw）/ 结构化知识（Wiki）/ 治理记录（Governance）/ 可重建索引（Index）四层；导入、人工审核、冲突处理、质量与过期检测、双链与图谱。
- **写作素材篮**：素材十类分类、待审核/已确认等五态审核、原文引用与来源定位、与任务/项目/知识双向关联，AI 只产候选、你确认后入库。
- **AI 文稿写作工作台**：写作任务（需求解析→素材收集→大纲确认→分章节写作→事实核验→审阅修订→定稿）；事实核验区分直接来源/冲突/无来源/分析判断等结论，口径冲突只提示不合并；版本快照与回滚。
- **导出与归档**：Markdown / Word（公文样式）/ PDF（阅读版式）/ 公众号 HTML 四种形态；定稿后 Markdown 归档进知识库，可勾选内容回流知识治理流程。
- **周报与成果归档**：周记录汇总、报告成果归档进知识库。
- **项目跟进**：事项、负责人代号、进度与逾期提示；最小项目实体关联任务、记录与素材。

## 设计原则

1. **确认制**：AI 只产生建议与候选，落盘、定稿、归档、状态迁移都由你触发；未经确认的内容不进入可信集合。
2. **事实优先**：文稿事实必须能追溯到素材或知识原文；无来源不编造，冲突不合并。
3. **临时层与知识层分离**：工作记录、任务、排期、素材篮、文稿存于本地工作区（不参与知识库检索）；只有经你归纳确认的成果（周报/总结/定稿文稿等）显式归档进知识库。
4. **数据自主**：会话、成果、配置全部在 `~/OmniDesk` 本地目录，仓库里只有代码与文档。
5. **权限可控**：本地 / 内网 / 外部模型分区授权，缺省关闭，由你在设置里自行决定开放范围。
6. **安全边界**：敏感内容在写入与模型调用前过红线扫描与脱敏闸门；工具入参/结果不进日志。

## 下载与安装

- 最新版本见 [Releases](https://github.com/klzone/omniharness/releases)：macOS 通用版 `.dmg` 与 Windows x64 `.exe`。
- 安装包内置 DSH 运行时与 Python 依赖模块（requests 等）；需要系统已装 Node.js 22+ 与 Python 3.10+，首次启动会做依赖自检并明确提示缺项。

从源码运行（开发）：

```bash
git clone https://github.com/klzone/omniharness.git
cd omniharness && scripts/setup.sh
scripts/omnidesk-dev.sh
```

需要自行配置模型端点（OpenAI 兼容接口）；未配置时应用可启动，模型相关功能不可用。

## 架构

| 层 | 技术 | 职责 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 + React + TypeScript | 窗口、场景页、对话与工作台 UI |
| 宿主 | Rust | 任务生命周期、写确认终检、权限判定、进程管理 |
| 适配层 | Python | DSH Web-API/ACP 通道、事件归一化、会话恢复 |
| 执行引擎 | DSH（锁定版本，不改核心） | 模型调用、工具执行、会话 |

数据根 `~/OmniDesk`（会话线程 / 成果 / 配置 / 日志），仓库不存任何用户数据。

## 项目边界

- 不修改 `runtime/` 下的 DSH Runtime；升级 DSH 先在副本跑回归。
- 真实业务材料、凭证、会话日志一律不进 Git；提交前有红线扫描。
- 不建设通用 Agent 平台、插件市场、微服务；按真实使用证据逐步扩展。
