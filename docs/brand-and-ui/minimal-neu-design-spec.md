# OmniDesk 极简新拟物设计规范（Minimal Neu v1）

> 状态：2026-11-25 用户裁决生效。本规范是全应用 UI 改造的权威依据。
> 参考样图：`docs/brand-and-ui/project-track-mock/index.html`（项目跟踪页落地稿）。

## 1. 一句话定义

**极简板式 + 新拟物材质**：大幅留白腾出空间，只保留重点文字；能用颜色、图标、形状表达的信息一律不写文字；控件与背景由同一块暖白材料挤出（凸起）或压入（凹陷）。

## 2. 文字规则（最激进的约束）

1. **取消描述性文字**。标题、副标题、说明句、计数徽标、图例、空态提示，全部优先用图标/颜色/形状替代。只有「用户必须读才能操作」的内容保留文字（任务标题、日期数字、表单值、按钮确认词）。
2. **图标代替标题**。面板不写「我的任务」「甘特图」这类标题，用一枚融入材料的凹底圆形图标钮表达区域语义（勾选框=任务、甘特条=时间线、文件夹=项目）。
3. **数字裸露**。统计只显示数字本身，语义由旁边的图标承担（对勾=已完成数、时钟=进行中数）。
4. **颜色即状态**。强调橙 `#a24e2c` 只表达「需要注意/进行中/主操作」；状态不用文字徽标，用条形颜色和圆点颜色表达。
5. **正文字号阶梯**：页面主标题 22px/700、项目名 14px/700、任务名 13px/600、辅助数字 11px、刻度 10.5px。字距：大数 -0.03em，正文 +0.01em。
6. **品牌标语保留**：首页空态保留书法标语「坚持学习人生的有无限可能」。它是品牌语气，不按描述性文字处理。

## 3. 材质规则（承袭 neumorphism-guideline.md）

1. 三层表面：底材 `#f2e9d8` → 凸起面 `#f3ebdb`（raise-1/2）→ 凹陷面 `#e9dfca`（inset-1/2）。
2. 单一光源左上；凸起双阴影（右下暖灰 + 左上白高光），凹陷反向内阴影。
3. 同一视图最多三层嵌套；阴影卡内不放阴影卡。
4. 强调色面积 < 10%，只用于主按钮、当前状态、进度、逾期警示。

## 4. 布局规则

1. **留白优先**：页面外边距 ≥ 24px，栏间距 ≥ 20px，面板内边距 ≥ 20px；行高紧凑但列间松。
2. **一屏一件事**：每个面板只承载一个语义（任务分组/时间线/项目卡）。
3. **左轨+画布**：时间线类内容用「左侧固定轨（项目名）+ 右侧画布（色条）」结构。
4. **信息在条内**：任务条高度 ≥ 28px，任务名、统计、图标都印在条内，不悬浮小字。
5. **项目跟踪页结构**：左栏 288px 纵向任务单元 + 右栏甘特与项目卡片。左栏默认展开「重要且紧急」「重要不紧急」，其余折叠；任务行单行显示状态点、重要/紧急标记、标题、右对齐日期或逾期天数。
6. **任务条内功能组**：甘特的编辑/删除功能组固定在条内右侧，悬停扇形展开；项目卡片的关联/加任务/复盘功能组固定在卡片左下，同样展开。
7. **项目跟踪页历史**：左栏底部放项目跟进分类的历史会话模块，默认折叠，点击会话回首页继续。
8. **状态弹层**：左上三个状态按钮（已完成/进行中/逾期）点击后打开居中任务清单，不在首屏直接铺开这些列表。

## 5. 交互规则

1. **图标功能组（Fan-out）**：无头像/无成员的模块，把「新建/关联/删除/复盘」等功能入口收进一组头像位大小的圆形图标钮；默认收拢成 2–3 枚可见，悬停时扇形展开（-24°/0°/+24° 旋转 + 位移），动效用 spring（overshoot 轻微），移出即收回。展开态图标凹陷变凸起 + 微缩放，触摸目标 ≥ 32px。
2. **按压即凹陷**：所有凸起控件 hover 变凸起加强、active 变凹陷（inset），不许只改颜色。
3. **动效参数**：transition 160ms ease 用于颜色/阴影；transform 用 240ms cubic-bezier(0.34, 1.56, 0.64, 1)（spring 感）。
4. **焦点可见**：focus-visible 显示 2px accent 环，键盘可达。

## 7. 落地优先级

项目跟踪页 → 工作记录 → 首页 → 文案写作 → 健脑室 → 历史会话 → 知识库 → 设置。
每页完成后跑既有 verify 脚本 + git commit。
