# OmniDesk 新拟物（Neumorphism）设计规范

> 状态：第一阶段（品牌靛 + 顶栏/首页）已于 2026-11-08 实施；其余页面待第二阶段批准。
> 日期：2026-11-08
> 适用范围：OmniDesk 桌面端浅色主题；首页顶栏优先，随后覆盖工作记录、文案写作、项目跟踪、设置与知识库。
> 预览：`docs/brand-and-ui/neumorphism-preview.html`

## 1. 一句话定义

新拟物不是“给卡片加阴影”，而是让控件看起来由**同一块材料**挤出或压入：浅色面与背景连续，左上受光、右下投影，凸起表示可操作，凹陷表示容纳内容或已按下。

参考图给出的核心气质是：暖白灰底、蜂蜜色强调、低饱和、轻量字重、圆润但不过分卡通。OmniDesk 第一批采用**暖白灰底 + 品牌靛强调**（用户 2026-11-08 裁决），保留参考图的暖底与材质语法，同时用明确的边界、焦点环和文字对比补足新拟物天生的可访问性短板。

## 2. 当前页面为什么显得平

现有 Aetheria 是“平面 + 半透明玻璃 + 细描边”的组合：

- 卡片主要靠 `bg-surface-container-lowest/80`、`ring-1 ring-white/90` 和很小的投影区分层次；
- 顶栏使用 `backdrop-blur-2xl`，玻璃感来自透明度，不来自材料厚度；
- 背景是淡紫白色光晕，控件与页面没有同材质关系；
- 按钮、输入框和卡片多数处在同一视觉高度，缺少“凸起 / 凹陷”的语法。

新拟物要补的是**材料厚度与操作状态**。它不应把所有东西都做成大阴影；应把页面分成三种明确的表面：承载页面的底材、浮起的内容面、压入的输入面。

## 3. 视觉语法

### 3.1 五条硬规则

1. **同材质**：控件底色与所在表面同色系。不要在白卡片上放一块灰按钮，也不要在灰底上放纯白卡片。
2. **单一光源**：光固定从左上方来。高光在左上，阴影在右下；凹陷控件反过来。全应用不得混用光源方向。
3. **成对阴影**：每个凸起至少一明一暗两层阴影；每个凹陷至少一明一暗两层内阴影。只做单向投影会退回普通卡片。
4. **最多三层高度**：底材、内容面（凸起）、输入/激活面（凹陷）。同一视图内不要出现第四层嵌套；不要在阴影卡片里再放阴影卡片。
5. **强调色是少量事件**：蜂蜜色只用于主操作、当前状态、进度和少量图标，面积控制在页面的 5%–10%。正文、边框和大部分图标使用石墨灰。

### 3.2 凸起与凹陷的使用语义

| 表面 | 视觉 | 用于 |
| --- | --- | --- |
| 凸起 L1 | 外阴影 3–6px，适合小控件 | 图标按钮、胶囊标签、日期入口、Dock 未选中项 |
| 凸起 L2 | 外阴影 8–14px，适合内容面 | 顶栏、对话面板、任务卡、设置分组 |
| 凸起 L3 | 外阴影 16–24px，只给页面主面 | 首页对话主面；一屏最多一个 |
| 凹陷 L1 | 内阴影 2–5px | 搜索框、输入框、开关轨道、滑杆轨道 |
| 凹陷 L2 | 内阴影 4–8px | 对话输入区、选中态、按下态 |

按下应“压回去”：普通按钮从凸起 L1 变为凹陷 L1，或至少把位移归零并加强内阴影。不要只改颜色。

### 3.3 光影公式

把偏移、模糊和透明度绑定，避免各组件随手写阴影：

- 小控件：偏移 3px，模糊 6–8px，暗影透明度 25%–40%，高光 80%–92%。
- 内容卡：偏移 8–10px，模糊 20–28px，暗影透明度 35%–45%，高光 88%–95%。
- 主面板：偏移 12–16px，模糊 32–40px，暗影透明度 35%–40%，高光 90%–96%。
- 凹陷：偏移与模糊取对应凸起的一半到三分之二，方向用 `inset`。
- 暗影颜色不是黑色，而是底色的暖灰加深：参考 `rgba(172,166,154,0.45)`。
- 高光不是纯白大面积泛光：参考 `rgba(255,255,255,0.92)`；大面积卡片可降到 0.85，避免发白。

### 3.4 与相邻风格的边界

| 风格 | 区别 | OmniDesk 是否采用 |
| --- | --- | --- |
| Flat | 无材料厚度，靠色块和留白 | 保留其排版与信息层级，不保留全平面控件 |
| Glassmorphism | 半透明、背景模糊、彩色折射 | 退出卡片与顶栏；只保留极少量静态暖光晕 |
| Material | 有明确投影和层级，控件与背景不同材质 | 不采用悬浮投影语言 |
| Claymorphism | 高饱和、强 3D、卡通粘土感 | 不采用；OmniDesk 保持克制、专业 |
| Neumorphism | 同材质挤出/压入，柔光双阴影 | 作为主语言，但必须叠加可访问边界与焦点态 |

## 4. 色彩令牌

参考图像素抽样得到的主色域：底色约 `#EAEAE8`–`#F1F0EE`，暗面约 `#DEDDDB`–`#CFCECD`，蜂蜜强调约 `#F5D37D`–`#FDD573`，正文约 `#535250`–`#666563`。下面把它整理成可用的令牌，并把文字对比拉到可读范围。

### 4.2 品牌靛方案（已采用，2026-11-08）

如果希望保留现有品牌识别，只换材质不换主色：

| 令牌 | 值 |
| --- | --- |
| `--neu-honey` | `#C7C4FF` |
| `--neu-honey-deep` | `#A9A4FF` |
| `--neu-honey-soft` | `#E4E1FF` |
| `--neu-honey-ink` | `#3525CD` |
| `--neu-focus` | `#3525CD` |

靛色填充按钮用白字；蜂蜜填充按钮用石墨字。不要用白字压蜂蜜色，也不要用靛蓝字压靛蓝填充。

### 4.3 对比度结论（按 WCAG 相对亮度计算）

- 主文字 `#3B3A37` / 底材 `#EDECEA`：9.63:1，满足 AA/AAA 正文。
- 次文字 `#666563` / 底材：4.93:1，满足 AA 正文；11px 标签也用它，不用 `#8A877F`。
- 蜂蜜填充上的石墨文字：7.85:1。
- 蜂蜜深填充上的石墨文字：6.22:1。
- 焦点环 `#6F520C` / 底材：6.16:1，满足 WCAG 2.2 焦点外观与非文本对比要求。
- `#8A877F` 只有 3.04:1，只可用于装饰线或非必要辅助文字。
- `#F5D37D` 对底材仅 1.23:1，不能作为文字或承载关键图标的唯一边界。

## 5. 阴影令牌

```css
:root {
  --neu-hi: rgba(255, 255, 255, 0.92);
  --neu-lo: rgba(172, 166, 154, 0.48);
  --neu-lo-soft: rgba(172, 166, 154, 0.30);

  --neu-raise-1:
    3px 3px 7px var(--neu-lo-soft),
    -3px -3px 7px var(--neu-hi);

  --neu-raise-2:
    8px 8px 20px var(--neu-lo-soft),
    -8px -8px 20px var(--neu-hi);

  --neu-raise-3:
    14px 14px 34px var(--neu-lo),
    -12px -12px 30px var(--neu-hi);

  --neu-inset-1:
    inset 2px 2px 5px var(--neu-lo),
    inset -2px -2px 5px var(--neu-hi);

  --neu-inset-2:
    inset 4px 4px 10px var(--neu-lo),
    inset -4px -4px 10px var(--neu-hi);

  --neu-pressed:
    inset 3px 3px 7px var(--neu-lo),
    inset -3px -3px 7px var(--neu-hi),
    0 0 0 1px rgba(150, 144, 132, 0.12);
}
```

使用约束：

- 每个元素最多三层 shadow；不要在外阴影上再叠 `filter: drop-shadow`。
- 不对 `box-shadow` 做逐帧动画；状态切换用 160–220ms 过渡即可。
- 大面积面板优先用 `--neu-raise-2`，只有首页对话主面用 `--neu-raise-3`。
- 弹层不能用 `backdrop-filter`；改用实色 + 双层外阴影 + 细高光线。
- `prefers-reduced-motion` 下取消位移与按压缩放，仅保留颜色/阴影的瞬时切换。

## 6. 字体、间距与圆角

### 6.1 字体

英文保持 Inter Variable 与 IBM Plex Mono（用户 2026-11-08 确认可接受）。中文界面统一用黑体，不再用宋体承担正文。

**设计判断：** 这是产品界面，不是 landing page 或印刷页。`design-taste-frontend` 明确把 serif 限定在编辑、奢华、出版语境；新拟物的低对比材质又最容易吞掉宋体细笔画。14–15px 的宋体在暖灰凹陷面上会出现明显“发虚”和横向闪烁，密集表格与对话更难扫读。因此宋体退出界面，只留给导出报告和打印文档。

| 层级 | 中文字体 | 用在哪 | 字重 / 字号 |
| --- | --- | --- | --- |
| 大标题 | 思源柔黑 / Source Han Sans Rounded SC，缺字体回退思源黑 | 首页问候、页面主标题、空态主标题 | 500–600 / 24–40px |
| 界面标题 | 思源黑体 / Source Han Sans SC | 区块标题、卡片标题、弹层标题、对话区标题 | 500–600 / 14–20px |
| 正文与控件 | 思源黑体 / Source Han Sans SC | 对话、说明、Markdown、按钮、表格、输入框、导航 | 400–500 / 11–15px，行高 1.65–1.7 |
| 标语/品牌 | 演示夏行楷 / Yanshi Xiaxingkai | 启动页、空态标语、品牌短句 | 400–500 / 17–28px，一页最多一处 |

**退出界面的字体：**

- 方正楷体只留给长引用、书信、落款等静态内容；不进入导航、按钮、表单、状态标签和表格。
- 思源宋体只用于导出报告、正式文档、打印页；不进入应用界面。
- 同一标题里不混用宋体、楷体或行楷。需要强调时用同字体的加粗或中等字重。

字体栈按“拉丁优先、中文回退”写，避免中文字体的拉丁字形影响英文：

```css
--font-display-hero: "Inter", "Source Han Sans Rounded SC", "思源柔黑", "Source Han Sans SC", "PingFang SC", sans-serif;
--font-headline-md: "Inter", "Source Han Sans SC", "思源黑体", "Noto Sans SC", "PingFang SC", sans-serif;
--font-body-md: "Inter", "Source Han Sans SC", "思源黑体", "Noto Sans SC", "PingFang SC", sans-serif;
--font-slogan: "Inter", "Yanshi Xiaxingkai", "演示夏行楷", "STXingkai", "Source Han Sans SC", cursive;
--font-accent-kai: "Inter", "FZKai-Z03", "方正楷体", "KaiTi", "Source Han Sans SC", sans-serif;
--font-report-serif: "Inter", "Source Han Serif SC", "思源宋体", "Songti SC", serif;
```

使用规则：

- 层级靠字号、字重、颜色和留白，不靠换字体。
- 中文标题字距 0 到 0.02em，不使用负字距。
- 等宽字体栈必须显式接中文黑体。`IBM Plex Mono` / `ui-monospace` 不含中文，若不接回退，日期、日历、卡片元信息会自动掉到宋体。
- 11–12px 的胶囊、状态、元信息用思源黑体 500，不用楷体或宋体。
- 正文 14–15px、行高 1.65；聊天 Markdown 行高 1.7。
- 行楷只做标语，首页欢迎短句用 700 加粗；其他界面句不再使用行楷。
- 字体缺失时回退系统黑体，不把回退字体固化成产品字体。

**字体可用性（2026-11-08 本机核对）：** 系统字体清单中只有 Songti SC / STSong / Heiti SC 等系统黑宋；未在本机字体目录、字体册清单或 Volumes 目录中找到思源黑体、思源宋体、方正楷体、演示夏行楷。应用已按上述字体栈优先引用，装入字体后即生效；本轮真实窗口只能验证系统黑体回退，思源柔黑与行楷的实际字形待装字体后再验。

字号与字重：

- 首页问候：30–40px，字重 300–500，行高 1.15，字距 0.01em。
- 页面标题：20–24px，字重 500。
- 卡片标题：14–15px，字重 500。
- 正文：14–15px，字重 400，行高 1.65；聊天 Markdown 1.7。
- 胶囊/元信息：11–12px，字重 500；使用 `--neu-ink-2`，不要用过淡的灰。
- 数字与时间：IBM Plex Mono，`tabular-nums`。

避免把整页做成细体。轻字重只用于欢迎语、大数字和视觉停顿；操作文字必须清楚。

### 6.2 间距

4 / 8 / 12 / 16 / 24 / 32 / 48。新拟物依赖留白让阴影呼吸：

- 控件内部横向：12–16px；纵向：8–12px。
- 卡片内边距：20–24px；卡片间距：16–24px。
- 顶栏左右内边距：20–24px；顶栏与内容之间：24px。
- 同一组控件间距不小于 8px；不同组之间 16–24px。

### 6.3 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--neu-r-sm` | 10px | 小标签、键帽 |
| `--neu-r-md` | 14px | 输入框、按钮 |
| `--neu-r-lg` | 20px | 卡片、弹层 |
| `--neu-r-xl` | 28px | 顶栏、对话面板 |
| `--neu-r-pill` | 999px | 图标按钮、胶囊 |

圆角必须与阴影方向一致：小控件圆角小、阴影近；大面板圆角大、阴影远。不要所有元素都用 999px 胶囊。

## 7. OmniDesk 页面结构

### 7.1 顶栏

顶栏是首页最需要“有触感”的位置。建议保留现有功能与真实状态，只换材质：

- 形态：悬浮圆角长条，高 64–68px，圆角 26–28px，距窗口顶部 18–20px。
- 底材：`--neu-surface`，不用半透明白，不用 `backdrop-blur`。
- 光影：`--neu-raise-2`，可额外加 `inset 0 1px 0 rgba(255,255,255,0.7)` 模拟顶部受光。
- 左侧：40px 凸起方形品牌座 + “OmniDesk”；Profile 徽标为凹陷胶囊，表示“当前运行配置”。
- 中部：搜索为凹陷输入面，聚焦时出现 2px 蜂蜜焦点环和 1px 暗线。
- 右侧：日期是凸起胶囊；设置、通知是凸起圆形按钮；窗口控制保留凸起小圆，关闭按钮悬停变为浅红底。
- 分隔：优先用间距和材料差分组，不用 1px 实线；必须分隔时用“上白下灰”的双细线。
- 拖拽区：`data-tauri-drag-region` 不变；按钮和输入框保持不可拖拽。

顶栏不要做整条渐变。参考图的立体感来自阴影，不来自金属渐变。

### 7.2 首页

建议顺序保持“问候 → 一条真实待办 → 全宽对话”，只增加一层材料：

- 页面底材：暖白灰 + 两个静态暖色径向光晕（不用 blur 滤镜）。
- 问候：直接落在底材上，不加卡片；大字号轻字重形成第一个视觉停顿。
- 待办：一行凹陷胶囊或轻凸标签，保持真实空态。
- 对话主面：默认**不包整幅大面板**。空态下整幅 `raise-3` 面板会形成巨大空白卡片（真实窗口试装已发现并撤掉）；只让输入区凹陷、消息气泡轻凸。若未来要使用大面板，必须先验证空态与低内容量下不显空。
- 消息：助手消息用平铺内容，不加阴影；用户消息用 `--neu-honey-soft` 的轻凸气泡。不要把每条消息都做成厚卡片。
- 输入区：对话面板内部的凹陷 L2，与面板形成“面板凸起 → 输入压入”的两层关系。
- 发送按钮：蜂蜜填充的凸起圆钮；键盘按下时变凹陷。

### 7.3 Dock

- 每个入口是 44–48px 凸起圆形按钮，间距 10–12px。
- 当前入口变为凹陷，内部图标保持石墨色，旁边用 4px 蜂蜜圆点表示当前位置。
- 悬停只做 1px 上浮和阴影增强，不做放大；禁用项降低对比度并保留占位。
- Dock 容器可以是一条窄的凸起轨道，但不要让轨道和按钮同时出现重阴影；优先“无容器，按钮直接浮在底材上”。

### 7.4 内容卡片

- 统一使用凸起 L2，背景 `--neu-surface`，圆角 20px。
- 卡片之间靠间距分组，不靠边框；需要边界时用一圈极淡的“上白下灰”双线。
- 卡片内部不再嵌套凸起卡片。列表行用凹陷分隔或纯间距。
- 指标卡只保留图标、标题、数值；不要英文副标题、序号和解释性小字。

### 7.5 表单与设置

- 设置分组用凸起 L2；分组内的输入框、开关轨道用凹陷。
- 开关：轨道凹陷，滑块凸起；开启时轨道填蜂蜜，关闭时轨道保持底材深一档。不要把滑块做成纯白，保持同材质。
- 复选/单选：未选中为凹陷小方块，选中为蜂蜜填充 + 石墨勾。
- 错误状态：保留凹陷形状，文字变深红，并加 1px 深红细线；不要整块变红。

## 9. 状态与动效

状态必须同时有“形状/阴影”和“文字/图标”两重线索，不能只靠颜色。

| 状态 | 变化 |
| --- | --- |
| Rest | 标准凸起或凹陷 |
| Hover | 上浮 1px，阴影提升一档；背景明度 +1%–2% |
| Active/Pressed | 位移归零，改内阴影；持续 80–120ms |
| Focus-visible | 2px 蜂蜜/靛色外环，外环与底材 ≥3:1；再补 1px 深色内线 |
| Selected | 凹陷或蜂蜜浅底，加左侧 3px 蜂蜜条 |
| Disabled | 保留形状，文字降到 45% 不透明度，去掉外阴影 |
| Loading | 只做 1s 透明度呼吸或静态点，不做阴影动画 |

动效曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`；时长 160–220ms。按压反馈 80–120ms。禁止持续漂浮、脉冲、背景模糊呼吸。

## 10. 可访问性门槛

新拟物的最大风险是“看起来像按钮”但边界不足。以下为落地验收项：

- 正文对比 ≥4.5:1；大字号 ≥3:1。次要文字使用 `--neu-ink-2`，不用 `--neu-ink-3`。
- 每个可操作控件必须有文字、图标或清晰形状中的至少两项；不能只靠阴影。
- 输入框、开关、滑杆等没有其他视觉线索时，边界与相邻表面 ≥3:1；可在默认主题加 1px `#8A877F` 细边，或用“对比模式”补足。
- 焦点可见：2px 外环，面积至少等于 2px 周长的矩形；焦点环对底材 ≥3:1；不得被顶栏或滚动容器遮挡。
- 不能只用颜色表示错误/成功/选中；加图标、文字或形状变化。
- 支持 `prefers-reduced-motion` 与 `forced-colors: active`：在强制颜色模式下放弃阴影，改用 1px 实线边界与系统色。
- 提供“增强边界”开关（预览页已示范）：打开后所有控件出现 1px `#8A877F` 线，焦点环更粗。
- 键盘顺序与语义不变；所有图标按钮保留 `aria-label`；弹层保留焦点管理和 Esc 关闭。

## 11. 性能门槛

- 不使用 `backdrop-filter` 做卡片、弹层或顶栏；新拟物用实色和阴影即可。
- 单页同时可见的 L3 面板最多 1 个；L2 卡片不超过 8 个（长列表滚动时只保留视口内的阴影）。
- 不使用 `filter: drop-shadow` 或大半径模糊做静态装饰。
- 动画只改 `transform`、`opacity`、颜色；不改 `box-shadow` 的模糊半径。
- 低性能设备/WebKitGTK 若出现掉帧，降级为 L1 + 1px 双线，不使用 L3。

## 12. Do / Don't

| Do | Don't |
| --- | --- |
| 同色系凸起/凹陷，光源固定左上 | 灰底上放纯白卡片，或反过来 |
| 一屏一个主凸起面 | 卡片套卡片，每层都加阴影 |
| 蜂蜜色只做主操作与状态 | 蜂蜜色铺满按钮、标题、图标 |
| 控件至少两项视觉线索 | 只靠淡淡的阴影识别按钮 |
| 实色 + 双层阴影做弹层 | 半透明模糊弹层 |
| 轻字重大标题 + 清楚的操作字 | 全页细体、低对比灰字 |
| 按下变凹陷 | 按下只变颜色 |
| 保留真实状态与空态 | 用装饰性假数据填满界面 |

## 13. OpenDesign 与外部参照

### 13.1 OpenDesign 已有内容

OpenDesign 本地官方库里有 1 个对应设计系统：

- 插件 ID：`design-system-neumorphism`
- 名称：Neumorphism / 新拟态
- 版本：0.1.0，MIT，first-party，2026-05-12 发布
- 描述：单色表面上用内外阴影塑造柔和、凸起的触感界面
- 其 DESIGN.md 给的令牌：Primary `#006666`、Surface `#E7E5E4`、Text `#1E2938`、字体 Space Mono / JetBrains Mono

这个包适合做“新拟物风格起点”，但没有给出双阴影方向、层级、按下态、焦点态和对比度门槛。它的青绿色 Primary 与参考图的暖蜂蜜也不一致，Space Mono 只覆盖拉丁字母，没有中文界面字体方案。OmniDesk 采用它的“同材质 + 内外阴影”原则；中文界面字体按本规范独立设计，不照搬 Space Mono。

在 OpenDesign 中没有找到现成的 OmniDesk 项目或新拟物页面文件；只有上述设计系统包。若后续要在 OpenDesign 里生成页面，可以在 Brief 中选 Neumorphism 设计系统，并把本规范作为附加约束。

### 13.2 截图库参照

按项目 UI 规则检索了同类产品，截图库中没有专门的新拟物标签；以下用于布局而非材质：

- **Navigator**（日历 / 工作区）：顶部一条搜索与操作，左侧窄日历栏，中间大留白内容区。借鉴：顶栏只保留高频入口，内容区靠留白分组。
- **Craft**（文档 / 工作区）：几乎无边框的白底画布，左侧窄导航，内容用字重和间距分层。借鉴：减少装饰性标签，让排版承担层级。
- **Notion**（笔记 / AI 输入）：底部固定输入条与行内控件。借鉴：对话输入区作为固定凹陷面，不与消息卡片争夺视觉高度。

三者的共同点是“低 chrome、清楚留白”；新拟物只在此之上增加材料厚度，不增加装饰噪声。
