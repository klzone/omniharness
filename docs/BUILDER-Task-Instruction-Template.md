# 子代理任务指令模板

> 用途：主 Agent 向执行子 Agent 派工时使用。简单任务可直接给一段自包含指令；需要明确边界、跨文件改动或独立验证时使用本模板。
> 默认模型：OpenDesign/deepseek-v4.1-flash-eco，思考等级 High。仅当 Eco 出现明确能力瓶颈时升级到 OpenDesign/deepseek-v4.1-flash，思考等级 High。

## 必备信息

- 目标：要解决的真实问题与期望结果。
- 范围：允许修改的文件或目录；明确不做的事。
- 上下文：相关代码、数据流、调用关系、既有模式与已知约束。只给必要信息，不让执行 Agent 从零扫描仓库。
- 验收：实际运行哪些命令、检查哪些行为、哪些风险必须覆盖。
- 交付：改动文件、实跑结果、未验证项、Git 状态。

    - 直接实施，不停留在建议、伪代码或计划阶段

    ## 安全与 Git
    - 不读取、打印或提交凭证；不接触真实业务材料、案件线索或未获准数据
    - 不修改 runtime/ 内 DSH Runtime
    - Commit 与 Push 按当前任务授权和 AGENTS.md 的 Git 策略执行

    ## 交付
    - 改动文件清单
    - 实际运行的命令与结果
    - 未验证项与已知限制
    - Git 状态
