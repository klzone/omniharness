# BUILDER 任务指令模板

> 用途：ARCHITECT（或用户）向 BUILDER 派工时，以本模板为底稿。模板只规定「怎么说清楚任务」，
> 不改变 AGENTS.md 的角色分工，也不放宽任何获批计划的范围。
> 状态：现行（2026-10-20 起）。来源计划：OD-ARCH-035。

## 固定条款

### UI 实现前先搜参考

任何涉及界面（布局、组件、视觉样式、交互动效）的实现，动工前必须先用
`screenshots-design-inspiration` MCP 搜索 2–3 个同类产品的界面作参考，
关键词示例：`chat workspace`、`sidebar dock`、`task dashboard`。

做法：

1. `search_inspiration` 取产品与图库链接，必要时 `get_product_screenshots` 查看具体页面；
2. 在实现说明里给出 **2 句以内**的借鉴要点（例如「左栏固定导航 + 主区单列对话」）；
3. 借鉴的是信息结构与交互取舍，不整页照搬，也不把截图硬编进仓库。

例外：纯逻辑、数据、测试、脚本改动不涉及界面时不适用。
MCP 不可用（网络或包启动失败）时如实说明并在 STATUS.md 记录，不得编造参考来源。
