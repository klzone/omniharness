## 二、八类核验结论（D-087）

1. 有直接来源支持（素材 source_quote 规范化匹配命中）
2. 有间接来源支持（知识依据或多素材合成）
3. 来源存在冲突（同对象不同结论并列）
4. 来源已过期（知识条目过期标记联动）
5. 无法找到来源（提示用户补充或删除，不编造来源）
6. 属于分析判断（AI 四分法标注，不得伪装已证实事实）
7. 属于工作计划（计划不写成完成，方案 §六红线）
8. 属于表达性概括（无具体事实，允许但不计入成果）

## 三、双引擎机制（609）

- 确定性层先行：正文提取数字/日期/机构名/人员职务 → 与 selected 素材 source_quote 及知识引用规范化匹配（复用 501 归一化函数）→ 结论 1/2/3/4/5。
- 口径冲突检测：同一指标不同时间范围/统计口径并列 → 输出冲突提示，不合并（场景七）。
- AI 层补充：分析判断/计划/概括分类标注由章节生成顺带产出（D-088 顺车，不新增调用），核验时合并（结论 6/7/8）。

## 四、引用追溯（603）

CitationRecord：段落定位 / 来源类型 material|knowledge / 来源 id / 引用原文 / 时间。段落→素材/知识定位双向可查；核验面板点击定位跳转对应段落（612）。

## 五、风险提示口径

无法核实≠自动删除：核验面板列出，用户决定补充或删除；口径冲突不合并只提示；分析判断显式标注；数据必留统计口径与时间范围；政策制度可查原文与有效性。
