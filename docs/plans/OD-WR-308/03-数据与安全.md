# 数据与安全边界

## 数据目录

- 临时层：$HOME/OmniDesk/work（env OMNIDESK_WORK_ROOT > settings.v1 working_root > 默认）。记录、任务、候选、回收与周文件存档都在这里。
- 知识层：用户选择的 vault；知识卡、报告与归档成果。
- 应用数据：$HOME/OmniDesk/app；设置、规则、引擎状态、线程记录与日志。
- 仓库：只放代码、测试、合成夹具与文档；用户成果不写回仓库。

## 红线与掩码

- 所有用户文本写入前统一走 gate_user_text：红线命中即拒绝，错误只报类别与数量，不回显原文。
- 覆盖点：记录标题/正文、任务标题、进展、状态备注、候选确认标题、拒绝备注、关联进展与备注、解析准备时的标题/正文。
- 身份证与手机号按 profile_rules::mask_privacy 掩码后落盘；回执只给类别与数量。
- 引擎提交唯一汇合点仍执行红线扫描与 mask_privacy；引擎侧 DataMasker 在 Task 4 已接主链（词典覆盖与真实质量未验证）。

## AI 权限

- AI 只产候选与状态建议；候选由宿主 validate_task_payload 校验后才暂存。
- AI 没有直接写任务文件、改状态或删记录的通道；引擎 task_extract.py 只读 stdin、只写 stdout。
- 候选确认/拒绝/关联均需用户显式动作；批量采纳逐条走同一校验。

## 端点准入

- 模型权限按 local / private / public 三类默认关闭，旧设置缺字段也按关闭。
- 提交前先红线扫描，再端点分类与授权准入；未许可时不启动引擎、不创建目录、不提交任务。

## 内容校验

- source_quote 必须是记录正文的连续原文，改写、拼接或概括整条拒绝。
- due_date 只接受正文明确出现的字面日期；模糊时间不得落精确日期。
- 未知字段、超限数量、非法置信度、终态关联目标、非法状态建议都会被拒。
- 去重键为 (record_id, quote 的 SHA-256)，重复候选跳过并如实计数。

## 测试数据

- 新模块的测试夹具全部为合成文本与 /tmp 临时目录；不读取用户成果、知识库正式材料或凭证。
- 关联、解析与 UI 验证脚本只做静态源码检查，不打开窗口、不调用模型、不读用户数据。

## 未验证事项

- 真实模型的提取质量、误报与漏报。
- DataMasker 词典的实际覆盖与回程还原质量。
- 真实 Tauri 窗口的观感与交互。
- 跨文件写入失败时的中间态恢复；当前只有单文件原子性。
- 大量记录/任务下的列表性能。
