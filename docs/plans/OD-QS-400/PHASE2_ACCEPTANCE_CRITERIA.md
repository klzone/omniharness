# 第二阶段验收标准（PHASE2_ACCEPTANCE_CRITERIA）

> 验收证据等级与落盘纪律照 IMPLEMENTED_RULES §3；全部测试使用虚构数据。

## 1. 四象限验收（对应任务 403/410）

- [ ] 高/低重要性 × 高/低紧急性 四组合各归正确象限。
- [ ] 重要性未知或紧急性未知→「待评估」，不强行归类。
- [ ] 无截止日期 + hint 模式外→紧急性待评估。
- [ ] 目标时间（due_kind=target）紧急度低于同日期硬截止。
- [ ] 已完成/已取消任务不出现在待办象限；暂停任务保留重要性。
- [ ] 逾期但低重要性任务：紧急度高但**不**强制进 Q1。
- [ ] 用户 override：显示「用户指定」标注；清除后回到派生。

## 2. 时间解析验收（对应任务 402）

- [ ] 明确日期/本月底/下周三/明天下午 各推定正确（按记录日期）。
- [ ] 近期/尽快/无时间要求→待评估，不产出精确日期。
- [ ] 跨月/跨年/闰年 边界正确。
- [ ] 推定结果标注「推定」。

## 3. 排期验收（对应任务 408/409/411）

- [ ] 单/多任务排期正确；同截止日期按重要性排序。
- [ ] 依赖：前置早于后置；环→conflicts。
- [ ] 耗时超最大时段→建议拆分；可用时间不足→unscheduled 附原因。
- [ ] 锁定与已确认：永不移动，冲突显式报告。
- [ ] 每日容量上限与机动时间保留。
- [ ] 任务提前完成/延期/新增/重排：stale 提示 + 调整留痕。
- [ ] 已确认计划保护：重新生成不改写。

## 4. 数据迁移与兼容验收（对应任务 401）

- [ ] 旧任务文件（缺新字段）读回=默认值，零迁移、零报错。
- [ ] 新字段写入后旧路径（只认旧字段的代码）不崩溃。

## 5. UI 验收（对应任务 410–412）

- [ ] 四象限文字标识不只靠颜色。
- [ ] 旧占位（weeklyQuadrants.ts / WeeklyQuadrants.tsx）已删除且无引用残留。
- [ ] 空态真实不造数；冲突醒目；信息不过度拥挤。
- [ ] 真实窗口目视验收（用户执行，登记未验证直至完成）。

## 6. 安全与稳定性验收（对应任务 413）

- [ ] 五个新 IPC 全过 gate_user_text（红线+掩码）。
- [ ] AI 无排期写通道（只能生成建议条目）。
- [ ] 排期失败不影响任务状态与文件。
- [ ] 无敏感信息进日志；测试数据全虚构；真实业务词零命中。
