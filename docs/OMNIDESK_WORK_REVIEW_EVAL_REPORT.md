## 二、合成基准结果

- 用例：12 项（WR-G01 ~ WR-G12），覆盖单条事实、多条合并、完成/待办、连续进展、重复任务、模糊时间、事实与推断、成果、敏感拒绝、知识关联、低置信度。
- 位置：tests/golden_tasks/work-review/（cases.json、outputs/、score_work_review.py、measure_work_review.py）。

| 指标 | 结果 |

| 候选数量准确率 | 1.0 |
| 需人工确认识别率 | 1.0（2/2） |
| 重复/连续进展识别率 | 1.0（2/2） |

## 四、未验证项

1. 真实模型在这 12 类输入上的提取质量、幻觉率，以及无 shell 工具面下的实际使用情况。
2. 用户修正率与确认率需要真实使用累积，当前样本只有 2 条。
3. Token 消耗：引擎 usage 块的实际字段形态未用真实模型确认。
4. 历史检索注入对模型判断的实际影响（相关性 vs 噪音）。
