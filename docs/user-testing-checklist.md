# OmniDesk 用户实测清单（真实模型）

> 用途：作者本人在**正式环境**里亲手跑一遍，判断链路能不能用。
> 状态：可照做（2026-10-21，OD-ARCH-047 第 3 步）。
> 证据等级：本文件里的"当前状态"来自**文件事实**（读配置、读源码）；下面每一步的"预期"是设计口径，只有你实际点完才算验证。

## 0. 跑之前先确认三件事

| 项目 | 当前实际情况 | 来源 |
| --- | --- | --- |
| 启动方式 | `scripts/omnidesk.sh`（正式环境；不注入合成端点、不设隔离变量） | 脚本头注释 |
| 应用数据根 | `~/OmniDesk/app`（设置、线程、待确认写入、台账） | `app_paths.rs` 默认值 |
| 成果目录 | `~/OmniDesk/workspace/artifacts` | `settings.rs` 默认值 |
| DSH 数据根 | `~/OmniDesk/runtime/dsh-home`（Profile `acp`） | `omnidesk.sh` 注释 |
| 引擎当前路由 | `agnescn / agnes-3.0-flash`，地址 `https://api.agnes-ai.cn/v1`（公网） | `~/OmniDesk/app/config/omnidesk-model.yml` 存在即生效 |
| 模型权限 | 公网=开，本机=关，私有=关 | `~/OmniDesk/app/config/settings.v1.json` |

注意：`yvan-work` Profile 里写的是 `opendesign / deepseek-v4.1-flash`，但引擎**优先用上面的 OmniDesk 覆盖文件**，所以现在实际跑的是 Agnes。两者不一致是预期行为，不是故障。

## 1. 开权限之前先看清端点

1. 启动 `scripts/omnidesk.sh`，左侧进设置。
2. 看「模型与端点」卡：应显示 `agnescn / agnes-3.0-flash`、地址 `https://api.agnes-ai.cn/v1`、类别「公网（内容会发往本机以外的地址）」。
3. 点「刷新端点信息」，状态不应变成"无法确认"。

**预期**：能读到 provider / model / 地址 / 类别 / 判定依据。读不到就别往下走，先把 DSH 侧的模型配置理顺。

## 2. 选模型（可跳过）

回到首页对话区，输入框上方的模型下拉可以换 provider / model / 思考等级。换完宿主会用新路由重启引擎，并提示"端点 xxx（类别 xxx）"。

**风险提示**：换模型不会替你判断数据该不该发出去，权限仍然按你刚才开的类别生效。

## 3. 周报起草（第一条真实链路）

1. 左侧进「周报与随记」。上方是输入区，每行 `日期 | 事项 | 状态`。
2. 先点「载入合成样例」，确认格式被接受。
3. 点「生成模型初稿」。第一次会启动引擎，可能要等几秒；等待期间界面应保持可操作。
4. 成功后在「模型初稿」文本框里出现可编辑文本，来源标注「模型生成、未复核」。

**预期**：失败时明确报错（例如权限未开 `endpoint_unconfirmed`），**不会**用模板文字冒充模型产出。中途「取消生成」应让任务落到 cancelled，而不是显示成功。

## 4. 保存要人工确认

1. 勾选「我已人工核对以上内容…」。
2. 点「保存成果」。人工保存走旧路径，落在成果目录顶层。
3. 右栏「成果档案」出现新文件，可点开只读查看。

模型或定时任务发起的写入不走这条：它们先变成"待确认写入"，见第 6 步。

## 5. 定时 AI 复盘

1. 设置页「定时与提醒」卡：勾选「启用定时 AI 复盘」，频率选「仅一次」，触发小时设成当前或下一小时。
2. 等前端 tick（约 30 秒一次）到点；或直接改配置里的 `once_at` 到过去时间（仅测试实例）。
3. 生效时 `last_review_at` 会推进，并生成一条待确认写入；此时成果目录**文件数不变**。

**预期**：权限关着时明确写"定时复盘未执行：模型权限未开启"，不产文件、不产模板。

## 6. 确认写卡

1. 设置页「数据与日志」卡里点「刷新待确认写入」。
2. 出现待确认卡片，写明动作摘要与影响范围（例如"在 weekly-report/ 下新建一个文件"）。
3. 点「确认写入」后出现回执，给出实际落盘路径，文件在 `artifacts/weekly-report/` 下。

**预期**：不确认就不落盘；记录 24 小时后自动失效；记录被消费后不能重复确认。

## 7. 出问题先看哪里

| 现象 | 先查 |
| --- | --- |
| 提示拒绝提交 | 设置页「模型权限」当前判定；端点是否"无法确认" |
| 生成失败但没有报错文案 | 首页底部状态行；公告栏降级说明 |
| 定时没触发 | 「定时与提醒」卡的状态摘要；应用是否一直开着（只在运行期触发） |
| 找不到成果 | 右栏点「刷新」；检查「含下级目录」开关 |
| 想确认没写脏数据 | `~/OmniDesk/app/engine-state/pending-writes/` 下的记录状态 |

## 8. 不要在正式环境做的事

- 不把案件材料、线索、未公开调查信息贴进任何输入框。
- 不用 `rm` 或脚本清理 `~/OmniDesk/app`、`~/OmniDesk/workspace`，要清理先备份。
- 不为了测试去改 `~/.dsh` 或 `~/.agents`；这两处不属于 OmniDesk。

## 9. 实测完记什么

每条只用一句话记：任务类型、是否完成、是否可用、返工类别、遇到的障碍。**不要**把输入正文、输出正文或真实业务内容写进使用记录。
