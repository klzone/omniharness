# 知识库链接语法矩阵（OD-KB-001 P3-S01）

本文件是 P3 链接解析的支持边界。解析器实现见 `desktop/src-tauri/src/vault_link.rs`，
目标解析与关系索引见 `desktop/src-tauri/src/vault_index.rs`。这里写的是**代码实际行为**，
不是期望行为清单；行为变化必须先改代码与黄金夹具，再改本表。

## 识别范围

| 语法 | 类型 | 目标 | 锚点 | 说明 |
| --- | --- | --- | --- | --- |
| `[[目标]]` | `wikilink` | `目标` | 无 | 笔记双链 |
| `[[目标\|显示名]]` | `wikilink` | `目标` | 无 | `\|` 之后为显示名，不参与解析 |
| `[[目标#标题]]` | `wikilink` | `目标` | `标题` | 标题锚点 |
| `[[目标#^块标识]]` | `wikilink` | `目标` | `^块标识` | 块锚点，`block_anchor=true` |
| `[[#标题]]` | `wikilink` | 空 | `标题` | 指向本笔记内部锚点 |
| `![[目标]]` | `embed` | `目标` | 可带锚点 | 嵌入，单独类型，不并入普通双链 |
| `[文字](目标)` | `markdown_link` | `目标` | 无 | 标准行内链接；`#` 属 URL 片段，不切分 |
| `![说明](目标)` | `markdown_image` | `目标` | 无 | 标准图片 |
| `<https://…>` `<mailto:…>` | `autolink` | URL | 无 | 外部目标，不参与笔记关系 |

每条引用都保留：原文起止字节、原文件行号（含 Frontmatter 行）、整行上下文（最多 120 字符）、
原始目标文本（未做 URL 解码、未规范化）。

## 不识别（保留原文，并显式报告）

以下写法不会进入关系表，原文按字节保留；同时在本行生成一条索引 issue，界面关系面板可见。
同一行同一类问题只报一次，避免异常文本刷满问题列表。

| 语法 | issue code | 处理 |
| --- | --- | --- |
| 引用式链接 `[文字][标签]` | `unsupported_reference_link` | 不产出链接 |
| 脚注 `[^1]` | `unsupported_footnote` | 不产出链接 |
| HTML `<a href>` | `unsupported_html_link` | 不产出链接 |
| 未闭合 `[[` | `unclosed_wikilink` | 退化普通文本 |
| 未闭合 `[x](` | `unclosed_markdown_link` | 退化普通文本 |
| 超过 512 字符的目标 | `target_too_long` | 丢弃该条，不截断成看似有效的目标 |

跨行链接文字或跨行 `[[`（下一行另起链接）不并入同一条引用，按各自行独立解析。
单文件超过 2,000 条引用时截断到上限，索引标记不完整（`truncated`，不是 issue）。
普通正文里的孤立 `[`、`]`、比较符 `<` 不产生 issue：只有以链接记号开头的片段才会被解释。

索引构建的问题（读取失败、扫描后变化、预算耗尽、扫描跳过等）与上面的语法问题共用
`issues` 通道，均带 `relative_path` 与 `code`；构建级问题会导致 `complete=false` 并给出
`incomplete_reason`，局部语法问题不会让整个快照失效。

## 不参与解析的区域

- Frontmatter（P2 解析已剥离；解析器只接收正文）。
- 围栏代码块 ``` 与 ~~~，含其内容与结束行。
- 行内代码 `` `…` ``。

## 目标解析优先级（P3-S02）

对每条内部引用，按顺序取第一个命中层级；同一层级出现多个候选即判 `ambiguous`，绝不任选。

1. 目标为空：解析为来源笔记自身（`[[#标题]]`）。
2. 目标含外部协议：`external`，不进入关系图。
3. 带扩展名：按文件名精确匹配（大小写敏感），再按大小写不敏感唯一匹配。
4. 含路径分隔符：先按根内相对路径（大小写敏感），再按来源笔记所在目录相对路径；
   仍无命中则按路径后缀唯一匹配。
5. 省略扩展名：按笔记文件名主干（stem）精确匹配。
6. Frontmatter 别名精确匹配（大小写敏感）。
7. 以上皆无：按大小写不敏感的主干、别名匹配；同层多个候选判歧义。
8. 命中附件（非 `md`/`markdown`/`txt`）：状态 `attachment`，作为附件引用保留，不建笔记节点。
9. 无候选：`unresolved`。

大小写差异只在第 3、7 层作为兜底；不会让 `A.md` 与 `a.md` 互相覆盖，命中多个仍判歧义。

## 锚点定位（P3-S03）

| 情况 | 结果 |
| --- | --- |
| 显式块标识 `^id` 唯一命中 | `exact`，返回块所在行 |
| 标题 slug 唯一命中 | `exact`，返回标题行 |
| 标题原文忽略大小写后唯一命中 | `exact`，按唯一匹配定位 |
| 同名标题出现多次 | 按文档顺序生成 `slug`、`slug-1`、`slug-2`；链接按 slug 精确定位 |
| 锚点不存在 | `unlocated`，回退到笔记顶部，绝不再跳到别的笔记 |

标题 slug 规则：转小写；空白折叠为 `-`；保留字母、数字、`_`、`-` 与 Unicode 文字字符；
其余标点删除。重复标题后缀从 `-1` 起按出现顺序递增。代码块内的 `#` 行不是标题。

## 未验证边界

- 未对真实 Obsidian 库做语法抽样，只用合成夹具。
- URL 百分号编码按字面保留，不做解码；含 `%20` 的目标按字面路径匹配。
- 不做 Obsidian 插图尺寸语法（`![[]] |300`）的尺寸解析，`|` 之后一律按显示名处理。
- 大小写不敏感文件系统上的路径行为未单独验证。
- 引用式链接的定义块、脚注正文与 HTML 链接只识别“出现在正文里的引用写法”，不解析其
  定义或渲染结果；跨行结构（续行标题、跨行链接文字）从未支持语法的角度保留原文。
