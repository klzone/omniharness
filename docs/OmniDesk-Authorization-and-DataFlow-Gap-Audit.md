## 2. 已明确允许的用途

严格限于原文范围，当前**唯一**被允许的真实数据用途是：

| 项 | 内容 |
| --- | --- |
| 用途 | **数据分析与生态研判**（且仅为个人分析使用） |
| 数据形态 | 必须已满足"不出现身份证、电话号码、真实姓名、真实工作岗位及真实工作细节" |
| 处理方式 | 经脱敏管理后 |
| 使用者 | 用户本人 |
| 是否可分发 | **否** |

除此之外，**允许的准备工作**（不需要额外授权）限于：

1. **合成数据**：完全虚构、不含任何真实人员/机构/案件/内部信息；
2. **许可范围内的公开资料**：公开发布的法规原文、公开政策口径等；
3. **经明确批准的数据**：用户就具体数据、具体用途给出明确批准的数据。

> 本阶段的实现（见 [OmniDesk-Task-Shell.md](OmniDesk-Task-Shell.md) 与纵向试点）**只使用第 1 类（合成数据）**。

## 4. 边界实现状态：代码已验证 / 仅文档说明 / 尚未验证

本节区分"边界是**由代码强制**的，还是**只写在文档或提示词里**"。**不得**只凭提示词或界面文案声称代码已强制。

### 4.1 代码已验证（有可运行的自动化检查）

| 边界 | 实现位置 | 强制方式 | 证据等级 |
| --- | --- | --- | --- |
| 桌面应用数据根不得落在原版 DSH / agent / Desktop 数据或 DSH 源码树 | `desktop/src-tauri/src/app_paths.rs` `assert_isolated()` | 命中禁止片段即**拒绝启动**（`exit(2)`） | `static` + `script`（7 个单元测试） |
| 应用数据根必须是绝对路径 | 同上 `resolve()` | 相对路径直接报错 | `static` + 单元测试 |
| 引擎隔离根不得是 `~/.dsh` / `~/.agents` / `deepseek-harness` | `engine_supervisor.rs` `validate()` | 校验失败即拒绝启动 | `static` + `script`（集成测试） |
| DSH CLI 入口必须存在且为绝对路径 | 同上 | 校验失败即拒绝启动 | `static` + 集成测试 |
| 引擎子进程环境变量最小集下发 | `engine_supervisor.rs` `child_env()` | 只下发 5 个变量 | `static` |
| 隔离启动脚本拒绝覆盖 Profile、拒绝落入原版数据根 | `scripts/omnidesk-dev.sh` | 硬校验后 `die` | `static`（`script` 路径已有历史记录） |
| 技能同步只允许写入 OmniDesk 隔离根；删除范围以托管清单为界 | `scripts/sync-skills.sh` | 目标越界即 `die`；源为空拒绝 `--delete` | `static` |
| 隔离自检（原版 `~/.dsh` / `~/.agents` 零变化） | `scripts/omnidesk-isolation-check.sh` | 快照比对 | `script`（历史 37/37） |

### 4.2 仅文档说明 / 仅提示词约定（**不构成代码强制**）

| 边界 | 位置 | 说明 |
| --- | --- | --- |
| 案件材料、案件线索、未公开调查信息禁止进入系统 | `skills/material-writing/SKILL.md` 第〇节、`skills/knowledge-search/SKILL.md`、`skills/document-review/SKILL.md` | 写入 **Skill 正文**，由模型在推理时自行遵守。**这是提示词级约束，不是代码强制**。 |
| 知识入库的分级与脱敏要求 | `docs/OmniDesk-Knowledge-Ingestion-and-Desensitization-Policy.md` | 规则文档 + 人工复核关卡；脚本只执行搬运，不做敏感判断 |

> **结论**：目前**没有任何一处代码**能强制阻止用户在输入框中粘贴案件材料或敏感内容。数据边界在"进入模型之前"这一段**依赖用户自律与 Skill 提示词**。
> 本阶段的纵向试点通过**只提供合成样例 + 不接入真实材料**来规避，而不是声称已有代码拦截。

## 5. 数据流与差距

本阶段真实处理路径（**只走合成数据**）：

```text
合成样例（仓库内 fixture，纯虚构）
   │
   ▼
OmniDesk 自有 UI（React/TS）
   │  ① 载入样例
   ▼
Rust 宿主：确定性统计（本地计算，不联网）
   │  ② 统计值（可复现）
   ▼
Python 引擎 → DSH CLI（隔离 Profile）→ 现有获准端点
   │  ③ 文字解释（**只解释，不重算**）
   ▼
人工确认
   │  ④ 用户确认
   ▼
仓库外本地数据目录（默认 ~/YvanAI/projects/Omnidesk/analysis/）
```

差距与阻塞：

| # | 差距 | 影响 | 本阶段处理 |
| --- | --- | --- | --- |
| G1 | 授权原件未在仓库中留存 | 无法在仓库内自证授权范围 | 本文件标注"用户转述"，不伪造原件 |
| G2 | 模型/服务商、设备、工具、运行环境四项待确认 | **真实数据不得进入** | 全程只用合成数据；真实数据路径保留但停用 |
| G3 | 数据边界在"进入模型前"无代码拦截 | 用户可能误贴敏感内容 | 试点不接入真实材料；将此列为需用户决策项 |
| G4 | 桌面外壳真实模型链路未验证 | 无法证明桌面端到端可用 | 本阶段实测；若端点不可用则记录阻塞，不伪造 |
| G5 | 使用记录是否真不含正文 | 有泄漏风险 | 由结构设计（记录字段无正文）+ 自动化测试共同保证 |

## 6. 本阶段结论与需用户决定的准入事项

**结论**：

1. 本阶段（个人自用 MVP）在**只使用合成数据**的前提下，**不需要**新授权即可开发和验证。
2. 一旦要接入**真实数据**，必须先取得原文范围内以及对模型/设备/工具/环境的**逐项书面确认**；
   且**只允许**"经脱敏管理的、用于数据分析与生态研判的个人分析使用"这一用途。
3. 现有代码能强制的是**路径边界**（不落到原版 DSH / agent / Desktop / DSH 源码）；**数据分级与内容边界目前不是代码强制**。

**需用户决定的准入事项**：

1. 是否就"模型/服务商、个人设备、工具、运行环境"四项分别给出书面确认（逐项）；
2. 除"数据分析与生态研判"外的用途（周报 / 材料撰写 / 项目管理）是否另行申请授权；
3. 是否需要在 UI 层增加**代码级**敏感内容拦截（当前没有）；
4. 真实数据落盘位置与留存方式是否被认可为上述"运行环境"确认的一部分。
