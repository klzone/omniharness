# OmniDesk Discipline 黄金任务验证集 (Golden Tasks v0.1)

本目录收录了 20 个面向纪检监察履职场景的脱敏基准任务，用于在 DSH 底座升级、模型切换或配置变更时执行自动化与人工回归验收。

## 任务分布
- **材料起草类 (GT-01 ~ GT-10)**：覆盖总结、汇报、发言、调研、体会、建议书反馈等高频文稿。
- **知识检索类 (GT-11 ~ GT-20)**：覆盖《党纪处分条例》《监察法》《问责条例》《公职人员政务处分法》等核心法规条文精确检索。

## 验收铁律
1. **材料类**：必须具备清晰三级大纲，符合规范公文结构，杜绝假大空套话。
2. **检索类**：必须严格满足 **答案 + 原文引用 + 来源文件 + 引用位置** 四要素，引用准确率必须 ≥ 90%，严禁杜撰条文。
