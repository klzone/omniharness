# 知识检索验收 · 合成夹具（全部为虚构内容）

本目录素材用于 OmniDesk P2「知识检索生效」的 6 类场景验收。规则：

- 全部为**虚构合成文本**：不存在真实人员、单位、机构、案件、数据、文号或内部信息；
- 单位名统一使用明显的占位写法「甲单位」；文件均标注「合成测试文本」；无真实文号；
- 关键事实为**虚构且非常规**的数值/编号，用于反记忆验证：
  - 专项检查：每季度不少于 1 次（非常规，易与「每年」「每月」混淆）；
  - 日常督查：每月不少于 2 次（现行）；
  - 督查报告：每月 7 日前报出；督查台账保存 5 年；
  - 问题线索移送：一处为 5 个工作日、一处为 7 个工作日（故意冲突）；
  - 另有一份「已废止」文件，日常督查每月不少于 1 次（旧值）；
- 严禁把真实制度文件、案件材料、线索或未公开信息放入本目录。

目录结构：

```
workdir/
└── knowledge/
    └── regulations/
        ├── 甲单位督查工作实施办法（合成试拟稿）.md
        ├── 甲单位问题线索管理办法（合成试拟稿）.md
        ├── 甲单位线索处置补充规定（合成试拟稿）.md
        └── 甲单位日常督查规定（合成·已废止）.md
```

`workdir/` 在每次运行时会整棵复制到一次性工作目录，作为被测实例的当前工作目录，
因此模型只能通过相对路径 `knowledge/regulations/` 检索到这些文件。

6 类场景与期望行为见 `docs/OmniDesk-Knowledge-Retrieval-Acceptance-Spec.md` 第七节。
