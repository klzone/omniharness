# OD-ARCH-043 证据索引：输入区与底部状态行的微调

> 执行日：2026-10-21。起因：用户两条微调要求 + 顺带补一个「打开时默认显示卡片」的缺口。

## 1. 改动

1. **删掉发送按钮前面的「↵ 发送」文字**（`HomeChat.tsx`）。
   同一处的另一分支「提交已关闭」也一并去掉：权限未开启时输入框的占位文字已经写明
   「模型权限未开启：可在设置中确认端点后启用」，不再需要重复提示。
2. **底部状态行居中**：「模型权限：已开启 · 外部」与「Token 上下文：—（引擎未上报）」两个模块
   由左对齐改为**居中**（容器加 `justify-center`；两模块与可选的「工作目录」提示同一行居中）。
3. **补上「打开时默认显示卡片」的缺口**（`SceneScaffold.tsx`）：
   窗口打开时 WebKit 会补一次 mousemove（只是「指针在窗口里」这一事实，不代表用户动过鼠标），
   此前它会立刻把卡片藏掉。现在**第一次 mousemove 只记录位置、不改层级**，
   之后只有位置真的变了才按指针位置判定 ⇒ 打开即显示卡片 ✓。

## 1b. 追加：取消提示移出输入框

「取消：引擎以 stopReason=cancelled 落定」原本渲染在**输入框内部**，会把输入框撑高一行。
现改为渲染在**底部状态行、Token 模块之后**（可选的「工作目录」提示之前），
输入框恢复固定高度。

## 2. 验证（真实窗口）

- `shots/od043-input-row.png`：打开即显示顶部卡片 ✓；发送按钮前无「↵ 发送」✓；
  底部两个模块居中 ✓。
- `shots/od043-generating.png` / `shots/od043-cancel-note.png`：真实端点发一条并中途「取消生成」，
  取消说明出现在**底部状态行 Token 之后** ✓，输入框高度不再被撑高 ✓。
