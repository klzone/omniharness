# OD-ARCH-042 证据索引：顶部卡片的「默认显示 / 静止恢复 / 输入时不打扰」

> 执行日：2026-10-21。起因：用户要求「软件打开时默认首页卡片是显示的；等鼠标 5 秒不动就再显示出来，
> 不然页面太空；不过鼠标在对话框区域移动的时候或焦点的时候，首页这些卡片就不显示了」。

## 1. 规则（最终口径）

在 OD-ARCH-040 的**互斥**规则（谁在焦点谁在上，另一个透明度 0）之上，加一条**静止恢复**：

| 情形 | 顶部卡片 | 对话 |
| --- | --- | --- |
| 刚打开（指针还没动过） | **显示** | 在卡片下方 |
| 指针在对话区（对话历史 / 输入框） | 隐藏（透明度 0） | 上移占满顶部 |
| 指针在对话区 + **鼠标静止满 5 秒** + 输入框**无焦点** | **重新显示** | 回到卡片下方 |
| 指针在对话区 + 静止满 5 秒 + 输入框**有焦点** | **不显示**（用户正在写） | 上移占满顶部 |

## 2. 实现

`desktop/src/shell/SceneScaffold.tsx`：
- 记录最后一次鼠标移动时间（`lastMoveRef`），每 500 ms 判定一次「是否静止满 5 秒」；
- 卡片是否让位由同一个开关决定：`chatExpanded = chatActive && !(idle && !inputFocused)`，
  **卡片与对话始终互斥**（不会重新出现半透明叠字）；
- 输入框焦点由对话组件上报（新增 `useChatInputFocus` 上下文，`HomeChat` 的输入框
  `onFocus`/`onBlur` 上报）。

`desktop/src/shell/HomeChat.tsx`：输入框的 `onFocus`/`onBlur` 上报焦点状态。

## 3. 验证（真实窗口，四态截图）

| 截图 | 情形 | 结果 |
| --- | --- | --- |
| `od042-1-open-cards-visible.png` | 刚打开 | 卡片**显示**（问候 + 三模块齐全） |
| `od042-2-pointer-in-chat-hidden.png` | 指针进入对话区 | 卡片隐藏，对话占满顶部 |
| `od042-3-idle-5s-cards-back.png` | 静止 6 秒（输入框无焦点） | 卡片**重新显示** |
| `od042-4-input-focused-stays-hidden.png` | 点进输入框取得焦点后静止 6 秒 | 卡片**保持隐藏** |

调试过程中的一处插曲（已排除、不是缺陷）：第一轮实测「静止后卡片不回来」，
原因是**上一轮测试点过输入框、焦点一直留着**——焦点态本就不该恢复卡片，
这正是规则里的一条。临时加入的状态输出（idle / focus / chat / 距上次移动秒数）已**移除**。
