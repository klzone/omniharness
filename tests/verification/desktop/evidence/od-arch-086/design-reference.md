# OD-ARCH-086 设置页库根卡片：界面参考记录

按 AGENTS.md（来源计划 OD-ARCH-035），动工前用 screenshots-design-inspiration 检索同类设置页。

检索：search_by_tags(["Settings & Preferences"]) 与 search_inspiration("preferences storage location folder")；
取 Shopify（Admin Panel/Settings）、TypeWhisper（Settings/Sidebar-driven/Developer tool）两款同类产品截图作参考。

借鉴要点：
1. 单条设置做成可折叠卡片，卡内固定「当前值 / 来源 / 修改入口」三段，避免整页表单堆叠。
2. 存储类路径设置把当前生效值和修改框分开显示，修改后只更新该卡片的状态行。

本轮只沿用 OmniDesk 现有设置页样式实现，未引入新布局体系。
