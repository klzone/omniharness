# OD-ARCH-038 证据索引：对话为主的工作台（悬停面板 / 宽对话 / 思考链可见）

> 执行日：2026-10-20。起因：用户实测三点 —— 思考等级的性能差异与思考链不可见、上半部分卡片挤占对话空间、
> 对话显示面积不足。

## 1. 思考等级：性能实测与呈现

| 思考等级 | 用户实测的响应 | 说明 |
| --- | --- | --- |
| 关闭 | **秒回** | 不传/关闭推理，工作台默认取这一档 |
| 中 | 约 5 秒 | |
| 高 | > 1 分钟 | |

→ 说明 `reasoningEffort` **确实生效**（否则三档不会有量级差）。工作台**默认改为「关闭」**（快），
其余档位仍在模型选择器里可切。

**思考链不可见的原因与处理：** DSH 的 **ACP 通道**在助手消息**提交时**才产出更新（块级，不是 token 级），
思考块与正文**同时到达**；此前适配层只上报思考的**字数**、丢掉文本，界面因此完全看不到。
现在：①适配层把思考文本一起上报；②界面在助手气泡里以**默认展开**的「思考过程（模型产出，不计入最终结果）」
区块展示；③本轮模型/端点没有返回思考时，如实写「本轮没有思考内容（该模型/端点可能不返回思考过程，或思考等级为关闭）」。

**诚实性：** 思考内容与正文**一起到达**（不是边想边出）——想要 DSH 网页端那种「边想边出」，
需要改用 harness 事件流（超出当前引擎契约，须单独批准）。

## 2. 对话区更宽

用户与助手气泡的宽度上限由 `max-w-2xl` / `max-w-3xl` 改为 **`max-w-[80%]`**（不超过容器的 80%）。

## 3. 卡片层级：**聚焦在前，其余渐隐**（用户最终口径）

**先做过的「上收 + 悬停浮出」已被用户否掉**（`PeekPanel` 已删除）。最终口径：
**不上收、不悬浮**；卡片**留在原位**，**鼠标在哪一块，哪一块在最前（z 序更高、透明度满），
其余卡片渐隐（透明度下降）到它后面**。

- 首页三块：机器人 / 今日重点推进 / 日程节律 ✓；
- 场景页三块：提醒/建议栏 / 本场景历史对话 / 成果·进度 ✓。

实现：每页一个 `focus` 状态 + 统一的 `layer(id)` 类名（`opacity-100 z-20` / `opacity-30 z-0`，200ms 过渡）。

截图（真实窗口）：`shots/od038-home-idle.png`（无悬停）、`shots/od038-home-focus-today.png`
（悬停「今日重点推进」→ 日程节律与机器人明显渐隐、今日重点推进在前）。
