# OD-ARCH-044 证据索引：Dock 悬停只保留小字提示

> 执行日：2026-10-21。起因：用户截图指出 Dock 图标悬停时**同时**出现两条信息——
> 图标右侧的小字提示（要保留）与图标下方的浏览器原生大号提示（要去掉）。

## 1. 改动

`desktop/src/shell/Dock.tsx`：Dock 按钮上的 `title` 属性改为 `aria-label`。

- `title` 会让浏览器/WebView **再弹一个原生提示框**（大号、黑色、显示在图标下方），
  与图标右侧我们自己做的小字提示重复；
- 改成 `aria-label` 后**可访问名不变**（读屏与自动化脚本仍按「周报与随记（模型起草）」等名字定位 ✓），
  但不再有原生提示框。

## 2. 验证（真实窗口）

`shots/od044-dock-hover.png`：悬停 Dock 第 4 项（项目跟踪）——**只有**右侧那条小字
「项目跟踪 · 模型起草」，图标下方不再有原生大号提示 ✓。

回归：`tsc` 0、`npm run build` 通过；本轮未改 Rust。
