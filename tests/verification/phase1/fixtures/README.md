# 材料写作端到端验证 · 合成素材（全部为虚构占位内容）

本目录素材用于 Phase 1 场景 1–6 的端到端验证。规则：

- 全部为**虚构**内容：不存在真实人员、单位、机构、案件、数据或内部信息；
- 单位名、人名一律使用明显的占位写法（如「甲单位」「张某某」）；
- 数字均为编造的演示数据，不来自任何真实统计；
- 场景 6 的素材是**纯虚构占位**，用于验证数据边界规则是否会拦截，
  不含任何真实案件线索或未公开调查信息；
- 严禁把真实案件材料、线索或未公开调查信息放入本目录。

这些文件会被 `tests/verification/phase1/run_material_writing_scenarios.py` 读取，
拼装成脱敏测试提示词。
