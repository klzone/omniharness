# 纪检材料空泛与失范表达避坑清单 (Avoid List)

## 1. 严禁使用的浮夸 AI 套词
- 严禁使用“深刻的不仅是...更是...” （AI 标志性假深刻句式）
- 严禁使用“全面赋能”、“打通底层逻辑”、“构建新生态” （互联网黑话，严禁入党政公文）
- 严禁使用“如春风化雨般...”、“宛如一盏明灯...” （文艺抒情泛滥，违背公文客观朴素原则）
- 严禁使用“在充满不确定性的浪潮中...” （虚浮空泛的无意义修辞）

## 2. 严禁使用的模糊空泛表述
- 严禁模糊表述：“在各级领导关怀下，取得了一定成效” -> 必须写明具体监督了什么、解决了什么。
- 严禁模糊表述：“加大了监督检查力度” -> 必须写明检查频次、覆盖对象、检查手段。
- 严禁模糊表述：“进一步提升了干部廉洁意识” -> 必须结合警示教育场次、受教育人数、通报典型案例数量来印证。

## 3. 严禁出现法规与政治性失误
- 严禁概念错误：将“四种形态”写成“四种方式”或“四项原则”
- 严禁次序混乱：将“不敢腐、不能腐、不想腐”顺序颠倒或漏项
- 严禁缩写截断：将法规简称或条款编号随意截断造词
- 严禁主观断言：随意使用带有案件定性倾向但无官方认定的主观评价词
