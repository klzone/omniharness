# Token 用量摘要

## 可确认结论

- 当前可用的平台用量信息是账户窗口百分比，不带 OmniDesk 项目标签，也没有输入、输出、缓存或费用明细，不能用来计算项目消耗。
- 历史审计会话记载曾从本地请求遥测按日聚合出约 2026-10-13 至 10-17 的数据，并提到一个长线程约 5,394 个请求、输入约 4.37 亿 Token（缓存输入约 4.19 亿）。但本次可见材料没有原始日志路径、筛选条件和明细，无法独立核对该线程是否专属 OmniDesk。因此这些数字是继承的历史测量线索，不列为本报告的已验证项目实耗。
- 用户所说累计约 10 亿 Token，当前无法精确统计或确认归属。不能把不同日期的账户/服务商遥测相加后直接称为 OmniDesk 消耗。

## 缺失数据

| 指标 | 结论 |
|---|---|
| 项目/任务级输入与输出 Token | 无可复核导出，未知 |
| 缓存输入 Token | 历史摘要有线程级数字，原始记录与项目归属未核实 |
| 缓存写入 Token | 无可验证明细，未知 |
| 每任务费用 | 无服务商价格与任务归属数据，未知 |
| 重试/恢复请求 | 历史摘要提及遥测恢复次数，但缺原始证据与任务映射，不计入确定统计 |

本报告不把推算数字混入实测值。后续试点只有在可读到请求级用量且能映射到执行线程时，才报告该试点的精确数；否则只报告计划轮次、返工轮次、人工介入、耗时和测试结果。
